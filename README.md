# NestBrAIn downloads

Installers for the NestBrAIn desktop app. Get the latest from [Releases](https://github.com/shivraj-ux/NestBrAIn-releases/releases/latest) or from https://nestbrain.netlify.app.

- Mac (Apple silicon and Intel): `NestBrAIn-mac-universal.dmg`
- Windows: `NestBrAIn-win-x64.exe`
- Linux: `NestBrAIn-linux-x86_64.AppImage`

This repository holds release files only. The app's source code is private.
